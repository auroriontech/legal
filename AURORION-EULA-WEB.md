2. SERVICE DESCRIPTION
═══════════════════════════════════════════════════════════════════════════════

2.1 Core Features
Aurorion provides AI-powered location-based exploration services, including:
• Voice-guided exploration with AI guides and characters
• Real-time location-based content and recommendations
• Interactive conversations with AI personalities
• Personalized cultural and historical narratives
• Voice transcriptions and TTS audio playback
• Community features and social interactions

2.2 Technical Infrastructure
The Service operates on the following infrastructure:
• Cloudflare Workers (application runtime)
• Cloudflare D1 (SQLite database for user data)
• Cloudflare KV (session storage)
• Cloudflare R2 (object storage for TTS audio, images, file attachments, and backups)
• Cloudflare Vectorize (semantic search capabilities)
• Azure OpenAI (AI-powered conversations)
• Azure Speech Services (voice synthesis and recognition)
• Azure Communication Services (email notifications)
• PostHog and Microsoft Clarity (anonymous analytics)
• Sentry (error tracking and monitoring)

2.3 Third-Party Services
The Service integrates with third-party authentication providers:
• Google OAuth (Google account sign-in)
• Apple OAuth (Sign in with Apple)
• Passkey authentication (WebAuthn standard)
